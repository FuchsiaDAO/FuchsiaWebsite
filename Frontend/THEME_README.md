# Fuchsia DAO Website - Nouns-Inspired Cyberpunk Theme

## 🎨 Theme Overview

This website now features a **Nouns.wtf-inspired design** combined with a **cyberpunk futuristic aesthetic**. The theme maintains the clean, minimal, and bold design principles of Nouns while incorporating the dark, neon-accented cyberpunk visual identity.

## 🌈 Color Palette

- **Primary**: `#FF3CAC` (Fuchsia Primary)
- **Secondary**: `#7B2FF7` (Neon Purple)  
- **Accent**: `#00E5FF` (Electric Blue)
- **Success**: `#39FF14` (Cyber Green)
- **Warning**: `#FF6B35` (Warning Orange)
- **Background**: `#0A0A0A` (Dark BG)
- **Surface**: `#111111` (Dark Surface)
- **Card**: `#1A1A1A` (Dark Card)

## 🎯 Design Principles (Inspired by Nouns)

### 1. **Clean, Centered Layouts**
- Large hero sections with centered content
- Generous whitespace (dark space)
- Clear visual hierarchy

### 2. **Bold Typography**
- **Londrina Solid** as primary font (bold, distinctive)
- **Space Grotesk** as fallback font (modern, clean)
- **Orbitron** for headings (cyberpunk aesthetic)
- Large, readable text sizes

### 3. **Card-Based Components**
- Subtle rounded corners (`rounded-2xl`)
- Hover effects with scale and glow
- Consistent spacing and padding

### 4. **Minimal Navigation**
- Clean, transparent navbar
- Simple menu structure
- Prominent CTA buttons

### 5. **Strong Visual Elements**
- Gradient text effects
- Subtle animations and transitions
- Glitch effects for cyberpunk flavor

## 🧱 Key Components

### Navigation
- **NounsNavbar**: Clean, minimal navbar inspired by Nouns
- Transparent background with blur effect on scroll
- Prominent logo with subtle hover animations

### Layout Classes
- `.hero-section`: Full-height centered hero sections
- `.container-base`: Consistent max-width containers
- `.card-base`: Standard card styling
- `.card-highlight`: Enhanced cards with gradient borders

### Button Styles
- `.btn-primary`: Gradient primary buttons
- `.btn-secondary`: Outlined secondary buttons  
- `.btn-ghost`: Minimal ghost buttons

### Typography
- `.heading-xl`, `.heading-lg`, `.heading-md`: Consistent heading sizes
- `.body-lg`, `.body-base`: Body text styles
- `.text-gradient`: Gradient text effect

## ✨ Cyberpunk Enhancements

### Background Effects
- **Cyber Grid**: Animated grid pattern
- **Floating Shapes**: Geometric shapes with animations
- **Gradient Overlays**: Subtle radial gradients

### Animations
- **Glitch Effect**: Text glitch animation for headings
- **Float Animations**: Geometric shapes floating
- **Pulse Glow**: Pulsing glow effects on interactive elements
- **Grid Movement**: Subtle grid animation

### Interactive Elements
- Hover effects with scale transforms
- Glow effects on focus/hover
- Smooth transitions throughout

## 📱 Responsive Design

- Optimized touch targets
- Readable typography on all devices
